# 추가·수정한 기능

'책 추가' 흐름을 하나의 `<form>`으로 묶고, 제출을 submit 이벤트로 처리한다. 책 제목과 시작일 입력에 도움말·글자 수·오류 문구를 연결했고, 같은 제목의 책이 이미 있는지 검사하는 조건과 저장 중·성공·실패 처리를 추가했다. 책장에 담은 책은 새로고침해도 남도록 브라우저에 저장한다.

# 입력 조건

- 책 제목(필수): 공백을 뺀 1자 이상, 60자 이내, 책장에 같은 제목이 없을 것 (띄어쓰기와 영문 대소문자는 구별하지 않음)
- 읽기 시작한 날짜(선택, 체크했을 때만):오늘 이후 날짜는 불가
- 입력하는 동안 글자 수와 조건 충족 여부를 보여 준다.
- 비었을 때, 공백만 있을 때, 같은 제목이 있을 때, 오늘 이후 날짜일 때 각각 다른 오류 문구를 보여 주고, 값을 고치면 바로 사라진다.


# 확인 순서

1. '책 추가 시작하기'를 누르고, 제목을 비운 채 '독서 상태 선택하기'를 눌러 빈 값 오류 문구가 뜨는지 확인
2. 1글자를 입력해 글자 수(`1 / 60자`)와 조건 충족 안내 문구로 바뀌는지 확인
3. 체크해 열리는 시작일에 내일 날짜, 없는 날짜를 숫자로 입력해 오류를 확인하고, 오늘이나 이전 날짜로 고치거나 삭제 후 오류가 사라지는지 확인
4. '내용 확인하기'를 거쳐 '책 추가 완료'를 눌러 저장 중 상태와 책장 추가를 확인
5. '다른 책 추가하기'를 눌러 입력과 안내가 모두 처음으로 돌아가는지 확인
6. 이미 있는 책 제목을 띄어쓰기만 다르게 다시 입력하여 중복 제목 오류 문구가 나오는지 확인, 고친 후 오류가 사라지는지 확인
7. 주소창에 `?save-error=1`을 추가하여 열고 저장 시 실패 문구와 함께 입력값이 유지되는지 확인

# 실패 처리

- 주소 끝에 `?save-error=1`을 붙이면 저장이 실패한다.
- 실패 안내를 보여 주고, 입력값은 그대로 둔 채 다시 시도할 수 있다.
- 코드 위치: `script.js`의 `persistBook()`, `bookForm.addEventListener("submit", ...)`, `setSubmitState()`
