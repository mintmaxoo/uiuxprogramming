# 4주차 반응형 수정 기록

## 확인한 문제
390px에서 폼이 오른쪽으로 정렬되어 보였습니다.
390px에서 소개 영역의 이미지가 화면 밖으로 나갔습니다.

## 수정한 내용
`form`선택자를 클래스 선택자(`.subscribe-form`)으로 바꾸었습니다.
768px 이하에서 소개 영역을 한 열로 배치했습니다.

## 달라진 점
이메일 입력창이 버튼과 같은 폭으로 정렬되어 보입니다.
390px에서도 소개 영역의 내용이 한눈에 보이고, 이미지가 화면을 넘어가지 않고 소개글 아래에 정렬되어 보입니다.

## 확인한 너비
1100px / 769px / 768px / 390px
