# 책들 - 책 추가 시작하기

## 사용자와 목표

- 사용자: 여러 책을 동시에 읽으며 기록을 하는 사람
- 목표: 지금 읽고 있거나 읽을 책을 추가하고, 그 내용을 확인한다.

## 사용자의 흐름

1. 이용 방법 확인을 체크하고 '책 추가 시작하기'를 클릭한다.
2. 책 제목을 입력한다. 비어 있으면 안내를 받는다.
3. 기본 기록 단위를 선택한다. 읽고 있는 책은 필요하면 독서 시작 날짜를 입력한다.
4. 책 제목, 상태, 독서 시작일을 확인하고 수정하거나 완료한다.
5. 책 추가 완료 안내를 확인하고, 필요하면 다른 책을 추가한다.

## 인터랙션 시나리오

1. 시작

- 행동, 이벤트: 확인 체크박스를 선택 후 '책 추가 시작하기'를 클릭한다.
- 조건: 체크박스가 선택되었는가?
- 반응, 다음 상태: 확인 후 버튼을 클릭하면 첫 책 추가를 위해 제목 입력 화면을 연다.

2. 책 정보

- 행동, 이벤트: 제목을 적고 '독서 상태 선택하기'를 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어 있는가?
- 반응, 다음 상태: 비어 있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 값이 있으면 저장하고 읽기 정보 입력으로 이동한다.

3. 독서 정보

- 행동, 이벤트: 추가하고 있는 책을 기본적으로 기록할 때 쓸 단위를 선택한다. 이미 읽고 있는 책은 날짜를 선택 입력하고 '이전' 또는 '내용 확인하기'를 클릭한다.
- 조건: 읽는 중을 선택했는가? 
- 반응, 다음 상태: 이미 읽고 있는 책을 선택했을 때만 시작일 입력 영역이 나타난다. '이전'을 누르면 값을 유지한 채 제목 입력 단계로 돌아간다.

4. 내용 확인

- 행동, 이벤트: 책 제목, 독서 상태, 시작일의 입력된 내용을 읽고 '수정하기' 또는 '책 추가하기'를 클릭한다.
- 조건: 수정인가, 완료인가?
- 반응, 다음 상태: '수정하기'를 클릭하면 값을 유지한 채 독서 정보로 돌아간다. 완료하면 완료 안내로 이동한다. 

5. 완료와 다시 추가

- 행동, 이벤트: 완료 안내를 읽고 필요시 '다른 책 추가하기'를 클릭한다.
- 반응, 다음 상태: '다른 책 추가하기'를 누르면 책 추가의 진행 상태를 모두 초기화하고 제목 입력부터 다시 시작한다.

## 테스트 결과

- 정상 경로가 시작 → 입력 → 선택 → 확인 → 완료로 정상 작동함을 확인했다.
- 제목 입력에서 빈 값이라면 에러 문구와 함께 입력창으로 포커스 이동으로 안내되었다.
- 이전, 수정하기 버튼을 눌러 앞의 과정으로 돌아갔을 때 설정된 값이 남아있고, 수정한 값이 바로 반영되었다.
- 다른 책 추가하기 버튼을 눌러 모두 초기화된 상태로 처음으로 돌아가 새로운 책을 추가할 수 있었다.
- 모바일에서도 구현된 사용자 흐름이 잘림 없이 보인다.
