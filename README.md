# 책들 - 내 책장 확인

## 새로 추가한 점

7주차 사용자 흐름에서 추가된 책의 결과를 다시 열기 위해 '내 책장' 목록에 쌓고 완료 화면에서는 그 책장으로 이동할 수 있는 버튼을 추가했다. 목록의 책을 눌러 입력했던 정보를 다시 열어 볼 수 있도록 했다.

## 사용자와 목표

- 사용자: 여러 책을 동시에 읽으며 기록을 하는 사람
- 목표: 추가한 책을 한곳에 모아 두고, 필요할 때 다시 열어 정보를 확인할 수 있다.

## 사용자의 흐름

1. '책 추가 시작하기'를 누르면 책 추가 화면 아래에 '내 책장' 영역이 같이 열린다.
2. 책을 추가하고 완료하면 책장에 카드가 쌓인다. 완료 안내 화면의 '책장으로 가기'를 눌러 책장으로 바로 이동할 수 있다.
3. 책장의 카드를 눌러 그 책의 상세 정보를 확인하고 닫는다.
4. 다른 책을 더 추가해도 책장에 담긴 책은 그대로 남는다.

## 인터랙션 시나리오

1. 시작

- 행동, 이벤트: 이용 방법 확인을 체크하고 '책 추가 시작하기'를 누른다.
- 조건: 책장에 담긴 책이 있는가?
- 반응, 다음 상태: 책이 없으면(결과 없음) 책 추가를 안내하는 문구만을 보여준다. 책이 있으면 책 추가 안내는 숨기고 추가된 책 카드와 함께 정보를 확인을 위한 안내 문구와 상태별 책 권수 한줄을 보여준다. 책이 없으면 위쪽 책 추가 화면에서 새 책을 추가하고, 책이 있으면 카드를 누르거나 다른 책을 추가한다.

2. 책 추가 후

- 행동, 이벤트: 하나의 책 추가를 완료하고 완료 화면에서 '책장으로 가기'를 누른다.
- 조건: 독서 상태가 읽는 중인지 읽을 예정인지?
- 반응, 다음 상태: 완료하면 책장에 새 카드가 생기고 '책장으로 가기'를 누르면 책장 위치로 이동한다. 추가된 책 카드에는 제목과 알약 모양의 독서 상태를 보여 준다. 읽는 중은 배경색이 있고, 읽을 예정은 테두리만 있어 구별된다. 책장의 권수 요약도 함께 바뀐다.

3. 책 정보 확인

- 행동, 이벤트: 책장의 책 카드를 클릭한다.
- 반응, 다음 상태: 책 추가하기에서 입력된 책의 제목, 독서 상태, 기본 단위, 시작일이 담긴 정보 창이 열린다. '닫기' 버튼 또는 ESC 키로 원래 화면으로 돌아간다.

4. 다른 책 추가

- 행동, 이벤트: 다른 책을 추가한 후 책장으로 이동해 목록을 확인한다.
- 반응, 다음 상태: 다른 책을 추가하면 책장에 담긴 책은 지워지지 않고 카드가 하나 더 쌓인다.

## 테스트 결과

- 정상 경로가 '시작 → 책 추가 후 → 책 정보 확인 → 다른 책 추가'로 정상 작동함을 확인했다.
- 책이 없을 때 책장으로 내려오면(결과 없음) 빈 책장에서 책 추가 안내 문구만 뜨는것을 확인했다. 
- 책 추가 도중 위쪽의 '책 추가 시작하기'를 다시 누른다면 입력 값을 초기화 해 새로운 입력이 되도록 코드를 수정했다. 이 경우에도 책장의 책은 그대로 남아있는것을 확인했다.
- 카드를 눌렀을 때의 정보가 그 책의 입력값이 그대로 반영되어 보인다.
- 다른 책을 추가해도 추가된 책의 목록이 남아있다.
- 제목이 길어도 카드 높이가 같도록 카드 너비를 넘어간 글자는 '…'으로 줄여 보여주도록 했다. 전체 제목은 정보 확인을 통해 볼 수 있다.
- 모바일 너비(390px)에서도 책장, 정보 창 등 구현된 사용자 흐름이 잘림이나 가로 스크롤 없이 보이고 조작되었다.
