## 11주차 웹 접근성 개선
- 개선한 요소: 대비 기준을 충족하는 갈색 계열로 색상 변경, 현재 필터 밑줄 표시, 이미지 설명·닫기 버튼·탭 제목 이름 갱신, 본문 바로가기, Esc 메뉴 닫기, 필터 결과 안내 및 빈 결과 '전체 보기' 복귀
- 정상 경로: 첫 Tab으로 본문 바로가기 표시 → Enter로 본문 이동 → 메뉴 클릭 시 해시·밑줄·탭 제목 변경 → 항목 입력·저장 및 필터 확인
- 다른 경로: '읽는 중' 책이 없을 때 '읽는 중' 필터 → 결과 없음 안내와 '전체 보기' 클릭 → 목록·초점 복귀 / 모바일에서 메뉴 열린 상태에서 Esc로 닫기
- 키보드 확인: 첫 Tab에서 본문 바로가기 확인, Enter·Space로 버튼·링크 실행 확인, Esc로 모바일 메뉴 닫기 및 초점 위치 확인
- 모바일 확인: 768px 이하 너비에서 모바일 메뉴 열기·닫기, 입력 폼, 주요 버튼 조작 확인
- 배포된 웹페이지: https://mintmaxoo.github.io/uiuxprogramming/
