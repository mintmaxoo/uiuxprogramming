# 10주

## 추가·수정한 기능
* `nav > ul > li` 구조의 상단 고정 메뉴를 구현하고, 로고 '책들'을 클릭하면 맨 위(`#top`)로 이동했다.
* '책 추가하기' 영역에서 이용 방법 확인 체크 시 활성화되는 '책 추가 시작하기' 버튼의 클릭으로 확인 상태가 `Local Storage`에 저장되어 재방문 시 안내 없이 책 추가 화면이 바로 나타난다.
* 내 책장을 처음부터 보이게 하고 '전체', '읽는 중', '읽을 예정' 상태별 필터와 책 수가 표시된다. 책이 하나도 없을 때와 선택 상태의 책이 없을 때의 안내 문구가 각각 나타난다.
* 다크 모드 버튼을 상단 메뉴로 이동하고 사용자 이름 입력을 제거했다. 768px 이하 모바일 환경에서 '메뉴 열기/닫기' 버튼으로 메뉴를 접고 펼칠 수 있도록 했다.

## 메뉴별 목적지
| 메뉴명 | 목적지 (`href`) | 내용 |
| :--- | :--- | :--- |
| **책들** (로고) | `#top` | 맨 위로 이동 |
| **주요 기능** | `#features` | 서비스의 주요 기능 탭 |
| **이용 방법** | `#steps` | 이용 방법 안내 |
| **책 추가하기** | `#start` | 이용 방법 확인(최초 1회)과 책 추가 화면(`#book-flow`) |
| **내 책장** | `#book-shelf` | 추가한 책 목록과 필터 |

* 주소에 `#`이 없으면 첫 메뉴('주요 기능')가 현재 위치로 표시된다.

## 필터 기준
* **필터 구분**: `전체` / `읽는 중` / `읽을 예정`
* **결과 없음 안내**:
  * **담긴 책이 하나도 없을 때**: 필터를 숨기고 '책장에 담긴 책이 없어요. 위에서 새로운 책을 추가해 보세요.' 표시
  * **선택한 상태의 책만 없을 때**: 필터를 유지한 채 '선택한 상태의 책이 없어요. 다른 상태를 선택해 보세요.' 표시

## 기능을 확인할 수 있는 조작 순서

### 데스크톱

1. 네 개의 메인 메뉴와 로고를 클릭해 해당 영역으로 이동 및 주소의 `#..`값과 메뉴 강조가 바뀐다.
2. 새로고침이나 뒤로 가기/앞으로 가기를 했을 때도 주소, 화면, 메뉴 강조가 일치한다.
3. `'읽을 예정'` 1권을 추가한 뒤 새로고침해도 이용 시작 안내가 다시 나타나지 않는다. 책 추가시 기존의 책 제목 입력·검증·저장이 정상 동작한다.
4. 완료 화면의 `'책장으로 가기'`를 눌러 `'내 책장'`으로 이동하고 주소, 화면, 메뉴 강조가 바뀐다.
5. 필터 세 개를 차례로 눌러 선택 표시, 버튼의 책 수, 카드 목록이 함께 바뀐다.
6. 읽는 중 책이 없는 상태에서 `'읽는 중'` 필터를 누르면 결과 없음 안내가 나타난다. `'읽는 중'` 책을 추가하면 안내가 사라지고 해당하는 영역에 카드가 보여진다.

### 모바일

1. 모바일 너비(390px)에서 `'메뉴 열기'` 클릭 시 접힌 메뉴가 나타나며 가로로 넘치는 요소가 없다.
2. 버튼을 반복해서 누를 때 메뉴, 버튼 문구, `aria-expanded`가 함께 바뀐다.
3. 링크를 선택하면 해당 영역으로 이동하고 메뉴가 닫힌다.
4. `Tab` 키로 보이는 링크와 버튼을 순서대로 이동할 수 있다.
